# fm-expense-form

Статическая форма записи траты для Telegram Mini App поверх hledger-журнала.
Один `index.html` без сборки и зависимостей, раздаётся через GitHub Pages.

Данных на странице нет. Каталог счетов и мест приезжает **фрагментом URL**
(`#c=<base64url(gzip(json))>`) от бота вместе с web-app-кнопкой; фрагмент браузер
серверу не отправляет, поэтому каталог не попадает ни в логи Pages, ни в кеш CDN.
Заполненная форма уходит боту через `Telegram.WebApp.sendData` — поля JSON
и есть поля транзакции.

Контракты версионированы (каталог `v:1`, схема отправки `v:1`): страница и бот
деплоятся врозь, и незнакомая версия отбивается внятной ошибкой, а не молчанием.

## Проверка

- `index.html#test` — встроенные самотесты: декодирование каталога (вектор собран
  тем же кодом, что у бота: gzip `mtime=0`, base64url без набивки), фильтры деревьев
  по типу операции, fuzzy-guard на новое место, сборка payload.
- Открытая без фрагмента или вне Telegram страница объясняет, что происходит,
  вместо пустой формы.

## Деплой

Разовый: Pages раздаёт ветку `main` из корня. Страница не пересобирается
при изменении данных — данные живут в URL кнопки.
