# fm-expense-form

Статическая форма записи траты для Telegram Mini App поверх hledger-журнала.
Один `index.html` без сборки и зависимостей, раздаётся через GitHub Pages.

Данных на странице нет. Каталог счетов и мест приезжает **фрагментом URL**
(`#c=<base64url(gzip(json))>`) от бота вместе с web-app-кнопкой; фрагмент браузер
серверу не отправляет, поэтому каталог не попадает ни в логи Pages, ни в кеш CDN.
Заполненная форма уходит боту через `Telegram.WebApp.sendData` — поля JSON
и есть поля транзакции.

Контракты версионированы (каталог `v:1`, схема отправки `v:1`): страница и бот
деплоятся врозь, и незнакомая версия отбивается внятной ошибкой, а не молчанием.

## Валюты и знаки после точки

Валюту форма не выдумывает: закрытый список валют и точность каждой приезжают
в каталоге полем `c` (`{"KZT":2, …, "USDT":8}`) — это `commodity`-директивы журнала.
Поле ввода суммы режет дробную часть по ним, а не по зашитым двум знакам: срезанное
здесь `0.23928074 USDT` приехало бы к боту правдоподобным, и его проверки такую
потерю уже не поймали бы.

У счетов, чью валюту задаёт сам счёт (`Assets:Binance:*` → `USDT`), в каталоге стоит
третий элемент `a[i] = [имя, тип, валюта]`. Форма подставляет её и поля выбора валюты
не показывает — лишний тап стоял бы на каждой покупке кофе. Правило живёт в боте
(`journal.currency_of()`); копии списка префиксов в статике нет, иначе форма
подставляла бы одно, бот ждал другого, и разошлись бы они молча.

Оба поля необязательные: каталог бота старее этого правила читается по-прежнему —
валюты берутся из запасного списка, точность у всех два знака.

## Проверка

- `index.html#test` — встроенные самотесты: декодирование каталога (оба вектора
  собраны тем же кодом, что у бота: gzip `mtime=0`, base64url без набивки), фильтры
  деревьев по типу операции, fuzzy-guard на новое место, подстановка валюты счёта,
  предел знаков после точки, сборка payload.
- Браузера под рукой может не быть: страница грузится в `node` с подставным DOM
  (`document.getElementById`, `location`, `window`), после чего гоняется
  `window.FM.runTests()` — тот же набор, что и на `#test`.
- Открытая без фрагмента или вне Telegram страница объясняет, что происходит,
  вместо пустой формы.

## Деплой

Разовый: Pages раздаёт ветку `main` из корня. Страница не пересобирается
при изменении данных — данные живут в URL кнопки.
